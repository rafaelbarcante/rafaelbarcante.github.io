Unreleased Action Roguelike Brick-breaker

  • StudioFortis Games
  • RoleSenior Game Designer
  • PlatformMobile

Project Overview

This game was developed under the studio’s new games incubator initiative. It is an action brick-breaker with roguelike elements, similar to Ball x Pit, but with monetized progression suited to the F2P market.

The game’s main differentiator is a mechanic where players combine projectiles of different elements to produce powerful reactions (e.g. water + electricity).

My Responsibilities

  • Responsible for all the design in the game: core gameplay, progression, monetization, etc.
  • Used agentic AI to implement my own designs in a fast-paced development environment.
  • Built AI-assisted tools for content creation, balancing, and even VFX editing.

Key Results

  • One of the highest-scoring prototypes of the incubator initiative.
  • Playtest results were solid and the game was greenlit for further development, but production halted when the studio closed.
