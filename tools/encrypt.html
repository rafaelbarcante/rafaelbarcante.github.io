Project page builder

Turns a project content file into a finished page for the projects/ folder, either open or password-locked. Everything runs in your browser; nothing is uploaded and the password is never stored.

Open page: images and videos load from the assets folder as normal. Anyone with the link can read it.

After downloading, move the file into the projects/ folder (replacing the old one). Locked pages are safe to publish; keep the content files in private-src/ private.
